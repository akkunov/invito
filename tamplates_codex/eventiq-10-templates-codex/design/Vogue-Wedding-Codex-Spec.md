# Eventiq — Vogue Wedding · Design handoff

## 1. Источник и рамки задачи

Утверждённый макет: `design/references/vogue-wedding/full-reference.png` (1536×1024). Четыре отдельных PNG нормализованы до 390×1048 CSS px. `geometry.json` — целевые измерения, снятые вручную с растрового референса и округлённые; исходные слои Figma отсутствуют. Шрифты и цвета — целевые проектные значения, подлежащие визуальной сверке, а не метаданные изображения.

Создать `templates/packages/vogue-wedding.v1.json`, slug `vogue-wedding`, name `Vogue Wedding`, category `WEDDING`. Это внутреннее рабочее имя эстетики модной редакционной съёмки; не использовать логотип, мастхед или утверждение о связи с журналом Vogue. Для публичного коммерческого названия рассмотреть Fashion Editorial. Ветка `feat/vogue-wedding-template` от актуального main. Прочитать DESIGN.md, UX-CONTRACT.md (если есть), текущие схемы, общий renderer, виджеты и тесты. Использовать Studio v2, UniversalMobileEditor и действующие API. Не переписывать существующие пакеты, черновики, публикации; не вмешиваться в параллельные работы. Все расширения движка — опциональные, типизированные, обратно совместимые и покрытые тестами. Не ветвить бизнес-логику по slug.

## 2. Композиция и правила

Обложка — журнальная полоса: название события с красной чертой, огромные прямые узкие serif-имена в две строки, чёрно-белый портрет пары, красная дата на светлой ткани, круглая стрелка вниз. Не перекрывать лица именами. Второй артборд: светлая бумага, текст приглашения, таймер с тонкими вертикальными линиями, программа с крупным временем и красными вертикальными акцентами, чёрно-белые горы внизу. Третий — контактный лист фотографа 1–2–1 с метками 01–04, прямыми краями и белыми зазорами; ниже фото места, красный pin и кнопка карты. Четвёртый — чёрная полоса с белым текстом, контурными полями, белой CTA и горным фото. Без курсивов, градиентов, теней, национальных орнаментов, внешних рамок телефона и декоративного округления всей страницы. Не добавлять логотип Eventiq в само приглашение.

Базовый viewport 390×844, DPR 1. Каждый артборд 390×1048; полная номинальная высота 4192. Публичная страница — естественный scroll без промежутков между секциями, max-width 500px (проверить существующее ограничение и не менять другие пакеты). Studio placement x=0,420,840,1260; y=0. Все координаты локальны, border-box. 320/360/375/390/412/430px: сохранять читаемость, touch targets ≥44 CSS px, поля ≥16 CSS px; не масштабировать живые инпуты ниже этих значений. Разрешить рост секций и перенос текста; форма, сообщения и длинные имена не обрезаются. Не менять десктопный редактор. Декор aria-hidden, locked и pointer-events:none, текст и фото независимы.

На обложке дата и стрелка находятся поверх светлой части фотографии: создать независимую спокойную светлую нижнюю область или непрозрачную подложку при пользовательской замене, не запекать текст и не использовать градиент. ## 5. Компоненты

### Галерея
Переиспользовать `stackedMosaic`: верхняя широкая фотография, две рядом, нижняя широкая. Высоты и ширины из geometry.json; номинальный зазор 6–8 px, радиус 0. Метки 01–04 — отдельные overlay-элементы, не часть JPEG; нумерация по текущему порядку, контраст на каждом фото обеспечить небольшим непрозрачным фоном при необходимости. При 1–3 фото перестроить раскладку без пустых слотов, 0 фото — скрыть/показать штатное empty state. Тап открывает существующий lightbox; swipe, стрелки, Escape, закрытие, возврат фокуса, accessible names. В редакторе выбирать слой вместо открытия lightbox, в preview сохранять обычное поведение. Если общему виджету нужны параметры индивидуальных пропорций, рамок или меток, добавить opt-in вариант с прежними defaults для старых пакетов.

### Фотографии
6 заменяемых ресурсов: обложка, четыре галереи, ресторан. Все — монохромные в демонстрационном оформлении. Для сохранения композиции при замене предложить общий опциональный grayscale-фильтр без изменения оригинального файла; если schema не поддерживает, добавить безопасный общий enum/preset и тесты на единообразие renderer. Сохранять кадрирование, не растягивать. Не требовать от пользователя подбора разрешений. Переиспользовать загрузчик с автоориентацией, конвертацией HEIC/HEIF, сжатием WebP/JPEG, загрузкой нескольких фото и полной заменой галереи. Не блокировать замену заполненной галереи. Ресурсы в `public/images/vogue-wedding/`: WebP, реальные размеры и sizeBytes, разрешённый backend registry согласно действующей архитектуре. SVG только безопасный локальный декор, LF через .gitattributes. Исходные crop PNG низкого разрешения; восстановить чистые фотографии без надписей и номеров, для обложки создать светлую ткань в нижней зоне. Не увеличивать растровый crop и не выдавать это за восстановление деталей. Не использовать изображение целого артборда в качестве фона. Горы — 2 отдельные декоративные фотографии или общий ресурс с безопасным рендерингом на светлом/тёмном фоне.

### Программа и таймер
Таймер связан с той же датой что и обложка, Asia/Bishkek, не захардкодить 185/10/24/36. Дни/часы/минуты/секунды 4 колонки, тонкая чёрная линия между ними. При истечении — штатное локализованное состояние. Программа: четыре строки (16:00, 17:00, 18:30, 22:00), левая колонка ~126px, красная вертикальная линия 2px, правая колонка с заголовком и описанием, разделитель между строками #D4D1CC 1px. Высота строк auto, ориентир 88–108 px, не обрезать описание. Изменяемые время и тексты через существующий schedule contract. Если текущая схема не хранит описание отдельно, использовать существующее совместимое поле либо опциональное типизированное описание, не кодировать его через HTML.

### RSVP и карта
Переиспользовать общий RSVP widget, без нового endpoint. Все поля — flex/grid flow в ширине из geometry. Имя: label + input type=text, autocomplete=name. Поле: transparent, 1px white border, radius 9, padding 19px, font-size 17, min-height 48. Радио: 1px white border, radius 9, 24px круг, расстояние до текста 20px, строка min-height 48px, gap 8px, нажатие по всей строке. Активное — белая внешняя окружность и внутренняя точка. Select: нативный popup допустим для мобильных ОС, стилизовать закрытый контрол, chevron 20px; при отказе гостей скрыть/отключить количество и отправить 0 по действующему контракту. CTA: белая заливка, ink текст, radius 10, min-height 62px, padding 16px, без тени. Map: 1px ink border, radius 10, min-height 52, прозрачный фон, icon 24px, корректный адрес из персонализации и валидная ссылка. Ресторан и адрес демонстрационные, не утверждать достоверность адреса. Scroll: круг диаметром 56px, 1px ink border, chevron 20px, прокрутка к следующей видимой секции. При reduced motion — без smooth scroll. Music: существующий каталог, только разрешённые источники, управление воспроизведением по тапу, компактная кнопка 44×44 в безопасной зоне, не перекрывать контент.

## 7. Motion и производительность

Один вступительный эффект: плавное появление имён 350–450ms с лёгким вертикальным смещением 6px, без блокировки чтения и layout shift; reduced motion отключает. Нет фоновых тяжёлых эффектов. Обложка приоритетна, остальные фото lazy loading; зарезервированные размеры, WebP, отсутствие CLS. Уважать safe-area и клавиатуру. Не менять глобальные стили Eventiq для этого пакета.
