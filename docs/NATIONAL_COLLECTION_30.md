# Kyrgyz National Heritage Collection — 30 invitation templates

8 wedding, 7 kyz uzatuu, 4 nike, 4 beshik toi, 3 tushoo kesuu, 4 anniversary. All 30 are registered in the catalog and editor with editable RU/KY texts and fixed SVG ornaments. They reuse the existing timeline program, gallery, music and draft system. National designs also appear as optional standalone covers.

Run `npm run test:national`. Production build requires `npm ci && npm run build`; RSVP/public publication remains backend-dependent.
