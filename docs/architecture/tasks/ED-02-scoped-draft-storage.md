# ED-02 — Изоляция локальных черновиков и гостевой перенос

Приоритет `P0`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Защитить два черновика одной версии и два аккаунта от смешивания.

## Текущее состояние

Реализация передана на `REVIEW`. [Контракт, ограничения восстановления, проверки и PowerShell](../EDITOR-DRAFT-INTEGRITY.md).

## Зависимости

[000](000-eventiq-4-1-foundation.md), [AUTH-02](AUTH-02-session-boundaries.md)

## Scope

Доработать существующий scoped v2 для отдельных гостевых черновиков и выбора другого облачного черновика из редактора. Спроектировать явное восстановление исторического снимка при проверяемом происхождении.

## Non-goals

Потеря старых ключей, автоматический перенос между пользователями, новая БД.

## Архитектурные требования

Миграцию читать обратимо и учитывать происхождение. Не показывать данные прошлого subject, очищать эфемерные ссылки по logout.

## План реализации

Переиспользовать формат v2. Проверить две копии одной версии из кабинета и переключение через выбор в редакторе. Определить проверяемые критерии происхождения v1 и показать перенос только при их выполнении. При неопределённом происхождении сохранить исходные байты. Проверить переподключение и storage errors.

## Acceptance Criteria

Переключение A/B и два drafts одной версии не смешивают правки. Старый draft с подтверждённым происхождением восстанавливается с согласия без потери оригинала. Если происхождение не подтверждено, снимок хранится без вывода его данных в другой сессии.

## Обязательные тесты

Unit storage, Browser offline/reload/Google cancel, account switch, ошибочный и старый payload.

## Миграции

Локальная версионированная миграция с idempotent fallback; server schema не меняется.

## Rollback Plan

Отключить перенос, оставить reader v2 и сохранить старые ключи и отдельные новые копии до безопасной процедуры.

## Definition of Done

Acceptance Criteria закрыты воспроизводимыми проверками. В реестре указаны SHA, PR, проверенная среда, результаты, ручная приёмка или основание «не применимо» и ограничения. Откат проверен в объёме задачи.
