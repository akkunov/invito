# CAT-02 — Детерминированный рендер версии обложки

Приоритет `P1`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Получать полноценный WebP из нужного coverPageId.

## Текущее состояние

Cloud-карточка использует первый доступный asset; detail уже умеет общий рендер.

## Зависимости

[VF-01](VF-01-love-story.md)

## Scope

Изолированный render job/CLI, размер 430 CSS px DPR 2, RU/KY и ожидаемые keyed states.

## Non-goals

Chromium на GET, массовые интерактивные iframe и подключение production bucket.

## Архитектурные требования

Читать закреплённый документ, фиксировать шрифт/таймер, запретить отправку RSVP, autoplay и незаявленные сетевые пути.

## План реализации

Сделать fixture реальных обложек; описать ключ version/locale/render revision; рендерить общий canvas в worker; проверить стабильность результата.

## Acceptance Criteria

Полный cover по выбранной странице, одинаковые артефакты при повторе, нет записи гостевых событий.

## Обязательные тесты

Playwright image regression, gated/static poster, отказ медиа, RU/KY, размеры и decode WebP.

## Миграции

Нет в render-only подэтапе.

## Rollback Plan

Отключить генератор и сохранить detail без derived карточек.

## Definition of Done

Acceptance Criteria закрыты воспроизводимыми проверками. В реестре указаны SHA, PR, проверенная среда, результаты, ручная приёмка или основание «не применимо» и ограничения. Откат проверен в объёме задачи.
