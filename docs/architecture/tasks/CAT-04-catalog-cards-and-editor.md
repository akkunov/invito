# CAT-04 — Общие карточки и связка каталога с редактором

Приоритет `P1`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Использовать версионное полное превью во всех вариантах карточки и правильный источник при переходе в редактор.

## Текущее состояние

Detail рендерит готовый документ; список и preview-button раздвоены; seed может побеждать совпавший cloud slug.

## Зависимости

[CAT-01](CAT-01-catalog-model-and-pagination.md), [CAT-03](CAT-03-catalog-cover-jobs.md), [ED-01](ED-01-draft-pinned-version.md)

## Scope

Общая карточка, thumbnail/detail/preview/choose по согласованной identity, подписи принятого дизайна и отказные состояния.

## Non-goals

Десктопный редактор, реальные цены и необратимая миграция legacy контента.

## Архитектурные требования

Список не запрашивает полные документы; показывать размеры WebP и placeholder. Использовать старые URL и tested resolver.

## План реализации

Соединить DTO и производные; заменить параллельную карточку адаптерами; проверить legacy/cloud переходы, focus и 100+ записей.

## Acceptance Criteria

Обе локали, карточка и detail совпадают по версии; редактирование открывает выбранный правильный источник; ошибочные обложки не ломают список.

## Обязательные тесты

Typecheck/build, routes, Playwright 100+ pagination and stale pin; сравнить request count Q-03.

## Миграции

Нет сверх CAT-03.

## Rollback Plan

Снять UI переключение и оставить старые маршруты и читаемые артефакты.

## Definition of Done

Acceptance Criteria закрыты воспроизводимыми проверками. В реестре указаны SHA, PR, проверенная среда, результаты, ручная приёмка или основание «не применимо» и ограничения. Откат проверен в объёме задачи.
