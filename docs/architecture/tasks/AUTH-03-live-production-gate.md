# AUTH-03 — Живая приёмка авторизации перед production

Статус BLOCKED до предоставления отдельного тестового стенда. Зависимости AUTH-01 и AUTH-02. Выпуск REL-02 зависит от этой задачи.

Проверить настоящий Google consent и обе локали callback, получение и открытие доставленной ссылки email, восстановление сессии и черновика, выход и отказ refresh. Пройти desktop, физические iOS Safari и Android Chrome с тестовыми аккаунтами, зафиксировать SHA, устройство, версию браузера и результат каждого сценария без токенов и персональных данных. Использовать [матрицу staging](../AUTH-SESSION-AUDIT.md). Loopback-тесты подтверждают технические контракты. Отметка DONE требует подтверждения живых проверок владельцем.
