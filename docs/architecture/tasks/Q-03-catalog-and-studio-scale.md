# Q-03 — Измерения производительности на 100+ шаблонах

Приоритет `P1`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Измерить границы выдачи, рендера, кабинета и Studio до точечных улучшений.

## Текущее состояние

Есть текущая пагинация и агрегаты, нет подтверждённого масштаба 100+ для полного UX.

## Зависимости

[CAT-04](CAT-04-catalog-cards-and-editor.md), [ACC-01](ACC-01-account-real-thumbnails.md), [ST-01](ST-01-studio-capability-audit.md)

## Scope

Synthetic fixture 100+ с seed/cloud, разные версии и asset types, trace SQL/network/LCP/INP/CLS.

## Non-goals

Массированный cache приватных данных, удаление карточек для ускорения, выдуманные полевые данные.

## Архитектурные требования

Фиксировать одинаковые устройства/условия; счётчики по slice. Публичный кеш допускает version scope, private остаётся no-store.

## План реализации

Зафиксировать базовые метрики; сравнить новый профиль с прежним; выделить одну измеренную коррекцию на PR.

## Acceptance Criteria

Отчёт содержит p95 запросов/SQL, payload и воспроизводимый capture, отдельно лабораторные/полевые показатели.

## Обязательные тесты

Benchmark repeat, browser 100+ pages/filter, auth oversharing test и Playwright trace.

## Миграции

Нет в измерениях.

## Rollback Plan

Убрать тестовый стенд/fixture, в отдельных оптимизациях использовать code/flag rollback.

## Definition of Done

Acceptance Criteria закрыты воспроизводимыми проверками. В реестре указаны SHA, PR, проверенная среда, результаты, ручная приёмка или основание «не применимо» и ограничения. Откат проверен в объёме задачи.
