# ED-04 — Desktop оболочка общего клиентского редактора

Приоритет `P1`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Перенести утверждённую структуру editor chrome на desktop без дублирования mobile.

## Текущее состояние

Общая мобильная оболочка уже в main; desktop адаптеры раздельны и прежней компоновки.

## Зависимости

[ED-01](ED-01-draft-pinned-version.md), [ED-02](ED-02-scoped-draft-storage.md)

## Scope

Холст, навигация, контекстные настройки и полный scroll, RU/KY и keyboard.

## Non-goals

Перестройка Admin Studio v2 и гостевого artwork, новая модель документа.

## Архитектурные требования

Использовать существующие renderer, поля и команды; сохранить доступность, undo/redo, замены фото и управление фокусом.

## План реализации

Сверить утверждённый концепт; связать панели с общей selection; проверить legacy/cloud и границы mobile; измерить render churn.

## Acceptance Criteria

Управление доступно с клавиатуры и pointer, холст не притворяется превью-растром, mobile регрессии отсутствуют.

## Обязательные тесты

Browser/Playwright desktop, mobile 320–430, RU/KY, zoom, photo/HEIC и regression screenshots.

## Миграции

Нет.

## Rollback Plan

Вернуть прежнюю desktop рамку и прежние адаптеры, сохранив данные.

## Definition of Done

Acceptance Criteria закрыты воспроизводимыми проверками. В реестре указаны SHA, PR, проверенная среда, результаты, ручная приёмка или основание «не применимо» и ограничения. Откат проверен в объёме задачи.
