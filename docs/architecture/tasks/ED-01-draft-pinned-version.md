# ED-01 — Открытие закреплённой версии облачного черновика

Приоритет `P0`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Открывать ранее созданный черновик по его версии после republish.

## Текущее состояние

Реализация передана на `REVIEW`. [Контракт, ограничения восстановления, проверки и PowerShell](../EDITOR-DRAFT-INTEGRITY.md).

## Зависимости

[000](000-eventiq-4-1-foundation.md)

## Scope

Авторизованное чтение исходной версии, контракта и медиа по draft identity; совместимые переходы.

## Non-goals

Silent upgrade, смена владельца, изменение старого гостевого релиза.

## Архитектурные требования

Авторизация по draft owner и workspace; версия берётся из записи, не из запроса; seed/legacy ссылки продолжают работать.

## План реализации

Воспроизвести V1 draft → publish V2; использовать private version payload; развести новый и существующий вход; обработать missing/outdated media.

## Acceptance Criteria

V1 открывается, редактируется и публикуется после V2 без подмены. Чужой ID не выдаёт метаданные, поля или signed URL.

## Обязательные тесты

Backend contract и PostgreSQL E2E, Browser V1/V2, no auth, foreign owner и legacy маршруты.

## Миграции

Нет по умолчанию; используем существующую связь.

## Rollback Plan

Отключить новый вход, сохранив черновики/версии и ссылки; задокументировать fallback без записи.

## Definition of Done

Acceptance Criteria закрыты воспроизводимыми проверками. В реестре указаны SHA, PR, проверенная среда, результаты, ручная приёмка или основание «не применимо» и ограничения. Откат проверен в объёме задачи.
