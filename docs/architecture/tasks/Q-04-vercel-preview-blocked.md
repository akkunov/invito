# Q-04 — Vercel Deployment Blocked

Приоритет `P1`. Статус `BLOCKED`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Восстановить Vercel Preview для проверок pull request и зафиксировать причину блокировки.

## Текущее состояние

Vercel сообщает `Deployment was blocked` для PR #81 и исходного `main`. GitHub Actions `quality`, `frontend-contract` и `postgres-api` прошли для принятого SHA Love Story. 27 ноября 2026 года владелец разрешил слияние PR #81 при указанной блокировке. Причину сообщение проверки не раскрывает. [PR #81](https://github.com/akkunov/invito/pull/81/checks) · [Vercel Preview](https://vercel.com/akkunovs-projects/invito/9WiP9hgfYvPtyGrjLr2G8LNCgU7h)

## Зависимости

Доступ к журналу деплоя и настройкам проекта Vercel для ответственного за инфраструктуру.

## Scope

Установить причину блокировки, исправить настройки Preview и подтвердить успешный запуск в тестовом pull request.

## Non-goals

Изменения приложения, рабочей базы данных, правил GitHub Actions и публикаций приглашений.

## Архитектурные требования и план

1. Открыть журнал заблокированного деплоя и сопоставить его с GitHub SHA.
2. Проверить интеграцию GitHub, разрешения Preview и конфигурацию окружения по фактам журнала.
3. Внести минимальное обратимое исправление и повторить деплой тестового PR с изолированным окружением.

## Acceptance Criteria и обязательные тесты

Сохранить ссылку на причину и исправление. На одном SHA проверить Vercel Preview и GitHub Actions, открыть Preview и проверить доступность страницы без рабочей базы.

## Миграции

Отсутствуют.

## Rollback Plan

Восстановить предыдущие параметры Vercel и отозвать тестовое изменение, если Preview или существующие проверки регрессируют.

## Definition of Done

Причина задокументирована, пробный Preview доступен, обязательные GitHub Actions успешны. В реестре сохранены ссылки на проверенный SHA и результаты.
