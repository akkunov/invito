# ENG-02 — Опциональные возможности движка для выявленных отклонений

Приоритет `P1`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Устранить общие ограничения, подтверждённые визуальным сравнением.

## Текущее состояние

Слои, responsive layout, виджеты и контракты существуют; список изменений определяет ENG-01.

## Зависимости

[ENG-01](ENG-01-renderer-fidelity-contract.md)

## Scope

По одному изолированному подэтапу на capability, например размер динамического слоя, маска или тайминг раскрытия, если проблема подтверждена.

## Non-goals

Ветки логики по slug, растр всей композиции и обязательная миграция всех старых документов.

## Архитектурные требования

Аддитивный Zod-контракт, совместимые default, одинаковые Studio/customer/guest семантики и валидация ссылок/ownership.

## План реализации

Для каждого случая зафиксировать failing fixture; расширить минимальный общий слой; протянуть serialization, binding и правки; переснять целевой и старый пакет.

## Acceptance Criteria

Устраняется конкретный дефект; предыдущие пакеты, формы и снимки рендерятся с прежними default; редактируемые поля остаются независимыми.

## Обязательные тесты

Studio core, responsive, personalization, package assets, old/new snapshots и Playwright diff.

## Миграции

Нет по умолчанию; опциональные поля JSON, при необходимости отдельно доказать миграцию.

## Rollback Plan

Откатить использование capability в пакете и читательском пути; предыдущая версия остаётся доступной.

## Definition of Done

Acceptance Criteria закрыты воспроизводимыми проверками. В реестре указаны SHA, PR, проверенная среда, результаты, ручная приёмка или основание «не применимо» и ограничения. Откат проверен в объёме задачи.

## Наблюдения VF-01

Кандидаты после проверки границ в ENG-01 — общая привязка декора к расширяемым строкам, общее открытие отдельных фото в галерейном диалоге, маска перехода новой обложки в небо и авторинг опциональных параметров текста. Метаданные и компактное оформление музыкального блока согласовать с [MUS-01](MUS-01-music-provider-contract.md) и [MUS-05](MUS-05-shared-music-player.md).
