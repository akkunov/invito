# TPL-01 — Идентификация десяти уже импортированных шаблонов

Приоритет `P0`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Восстановить соответствия исходного дизайна и существующего ID.

## Текущее состояние

Коллекция есть в Git, импорт в рабочую БД подтверждён владельцем. Её реальные ID, head и опубликованные версии из репозитория не видны.

## Зависимости

[000](000-eventiq-4-1-foundation.md)

## Scope

Проверяемое read-only сопоставление и обезличенный реестр версий.

## Non-goals

Операции записи, повторный импорт, публикация, копирование гостевых данных.

## Архитектурные требования

Опираться на workspaceId + templateId, slug и хеши; не считать визуальное сходство идентичностью.

## План реализации

Собрать локальные slug и package hashes; на разрешённом read-only стенде сопоставить identity; вынести коллизии, отсутствующие и неподтверждённые строки в отдельный отчёт.

## Acceptance Criteria

Для каждого slug указаны существующий ID либо причина остановки, head и public version, основание сопоставления и read-only происхождение.

## Обязательные тесты

Disposable PostgreSQL с несовпадающими workspace, конфликтом slug и неизвестной версией; доказать отсутствие записи.

## Миграции

Нет.

## Rollback Plan

Отозвать временные права чтения и удалить локальный служебный экспорт по правилам хранения; данные БД остаются прежними.

## Definition of Done

Acceptance Criteria закрыты воспроизводимыми проверками. В реестре указаны SHA, PR, проверенная среда, результаты, ручная приёмка или основание «не применимо» и ограничения. Откат проверен в объёме задачи.
