# 000 — Eventiq 4.1 Development Foundation

Приоритет `P0`. [Реестр задач](../PROJECT-STATUS.md)

## Цель

Оставить следующий сеанс с проверяемой картой проекта, приложенными доказательствами и независимыми задачами.

## Текущее состояние

Актуальный main содержит влитый 4.0 PR #79. На стартовом SHA файла AGENTS.md и плана 4.1 не было.

## Зависимости

Актуальный origin/main и мандат TASK 000.

## Scope

Аудит кода и Git, архитектурные правила, план, фактические статусы, зависимости и PR только с Markdown.

## Non-goals

Продуктовый код, production-БД, реимпорт коллекции, реализация следующих задач и merge.

## Архитектурные требования

Начать от свежего origin/main в docs/eventiq-4-1-foundation. Историю предыдущих ADR сохранить, доказательства отличать от предположений.

## План реализации

Прочитать документы и выборочно проверить код и миграции; сверить merge/CI; выполнить безопасные проверки текущего кода; составить карточки и граф; проверить diff и открыть PR.

## Acceptance Criteria

Есть постоянные инструкции, карта, план, статусы, решения, отдельная задача для всех десяти визуальных проверок, непротиворечивый граф и SHA/PR. Следующая задача VF-01.

## Обязательные тесты

Структура документов, ссылки, покрытие всех ID и десяти пакетов, DAG, git diff --check, scoped документальный diff; продуктовые проверки только как baseline.

## Миграции

Нет. Рабочая БД не используется.

## Rollback Plan

Откатить документационный PR либо его коммит. Исходный код и данные не менялись.

## Definition of Done

Документы проверены, ссылки и граф валидны, diff состоит из Markdown. Ветка и SHA указаны в реестре, PR открыт, merge ожидает пользователя. Следующая задача не начата.
