## Совместные проверки

- Frontend и backend typecheck и production build прошли. Frontend regression scripts прошли, публичные маршруты были повторно проверены после новой сборки.
- На отдельной PostgreSQL 17 применены семь миграций. Тесты API прошли 19/19 unit и 5/5 E2E.
- Browser и Playwright использовались для исходного аудита и проверок в Chromium. Для фильтра каталога проверены облачный результат без ложного пустого состояния и локализация detail. [Поиск RU](qa/catalog-filtered-ru.webp) · [Поиск KY](qa/catalog-filtered-ky.webp)
- Root lint всё ещё сообщает 52 ошибки и 52 предупреждения. Исходный результат был 78 ошибок и 53 предупреждения. Scoped lint новых модулей и исправленного каталога прошёл. Проверка Frontend Design Premium для настроенных source roots прошла.

## Поставка и откат

Новая миграция `20261124010000_pin_catalog_template_version` добавляет ссылку на публичную версию. На disposable PostgreSQL 17 проверены backfill, ownership, сохранение существующего черновика после повторной публикации и отказ для устаревшей версии. Production-база и её снимки не изменялись. Для отката приложения оставляем additive колонку и возвращаем код предыдущего релиза. Выключение Google через флаг сохраняет email-вход.

## Оставшиеся этапы

- Автоматическое формирование полноценных версионных WebP-обложек каталога, хранение производных в R2 и единая модель карточек. Облачные карточки всё ещё используют прежний арт-ресурс и отдельный UI. Кабинету нужны готовые миниатюры и QR.
- Открытие более старого облачного черновика в браузерном редакторе после смены публичной версии, изоляция персистентных ключей и редактор 4.0 для desktop.
- Подтверждение WhatsApp-номера, согласие, outbox, worker и webhook. Доставка требует настроенного тестового WABA и утверждённого utility template.
- Интерфейс `MusicProvider`, Audius, модерация, поиск, единый проигрыватель и настройки фрагментов. Проверка прав на доступные треки и ограничения браузеров описаны в плане.
- Live Google и доставка email требуют настроенного тестового проекта Supabase. iOS Safari, WebKit и физический Android не подтверждены на этой среде.
