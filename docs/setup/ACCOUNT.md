# Личный кабинет Eventiq

`/[locale]/account` и совместимый `/[locale]/invitations` используют один интерфейс. Вход выполняется через общий Supabase Auth. В кабинете есть обзор, список приглашений с пагинацией, ответы гостей и профиль с выходом. Загрузка, пустое состояние, сбой и повторная попытка имеют отдельные состояния. Мобильная навигация расположена внизу. Для RU и KY используются токены и шрифт действующего лендинга.

## Данные и доступ

`GET /api/v1/customer/account/overview?page=1&limit=8` за один HTTP-запрос возвращает итоговые показатели, страницу черновиков со статусами публикаций, статистику каждой публикации на странице и пять последних ответов. Каждый запрос касается только текущего владельца. `attending` — сумма участников в ответах YES, `declined` — число ответов NO. Закрытые публикации могут иметь историческую статистику. `drafts` считает приглашения, для которых ещё не создана публикация. Старые API черновиков, публикаций и RSVP продолжают работать.

Закрытие доступа, копирование ссылки, открытие редактора и постраничный список гостей используют прежние API. Данные прошлого аккаунта очищаются при смене Supabase subject. Миграций у этой части нет. Откат приложения возвращает прежний интерфейс по `/invitations`.

## Проверки

Реальный PostgreSQL проверил пагинацию, сумму гостей, последние ответы и изоляцию двух подписанных пользователей. Неавторизованный запрос получил 401. В Playwright Chromium проверены RU/KY, ширины 320/360/375/390/412/430 и 1440 px, один запрос загрузки обзора, навигация, постраничная загрузка, список гостей и очистка после выхода. На снимках показаны синтетические данные.
