# INVITO v0.3 — девять шаблонов по загруженным изображениям

**Статус:** frontend-прототип. Элементы вручную адаптированы для веба по визуальным референсам, не являются пиксель-в-пиксель HTML-копиями исходных PNG. Основной код сохранён из v0.2.

## Что можно изменять

- Содержимое: имена, заголовок RU/KY, приглашение RU/KY, дату, место и город.
- Обложка/фото: выбрать JPEG/PNG/WebP/AVIF до 10 МБ; в браузере уменьшается и сохраняется в localStorage. Вертикальное положение — ползунок.
- Цвет акцента и видимость/порядок блоков.
- **Фотогалерея**: до 6 изображений, реальная секция с изображениями в предпросмотре вместо заглушки; загрузка и удаление в правой панели «Фотогалерея».
- **Программа**: до 8 этапов с временем, заголовком и описанием отдельно для RU и KY. Scroll-driven линия и появление этапов с IntersectionObserver; работает внутри preview-scroller, учитывает `prefers-reduced-motion`.
- **Музыка**: загрузка MP3/M4A/OGG/WAV/WebM до 12 МБ в IndexedDB; имя файла и удаление в секции «Музыка», плеер в контенте внизу, включение только по кнопке (браузерное ограничение autoplay).

## Несменяемые узоры

`src/features/invitations/reference-templates.ts` хранит закрытые для пользователя ссылки на `decor` из `public/images/reference/*-ornament.png`. Декор отрисовывается отдельным `<div class="reference-fixed-ornaments">`, **поверх** сменяемого изображения, без возможности загрузить новый узор через редактор. Иллюстрации выделены из **предоставленных пользователем** PNG; старые имена/даты не добавляются в узор.

Для вариантов без рисованных боковых элементов (девичник, фото-коллаж) композиция зафиксирована через CSS. При загрузке пользовательского фото оно меняет только слой `reference-cover-photo`, не затрагивает декоративные ассеты.

## Общее устройство

- `reference-templates.ts`: 9 конфигураций и дефолтные RU/KY-данные.
- `reference-hero.tsx`: составная обложка с независимым декоративным слоем.
- `reference-invitation.tsx`: программа, сообщение, дата, галерея, RSVP.
- `reference-template-artwork.tsx`: миниатюры в каталоге.
- `gallery-block.tsx`: общий визуальный рендерер фото для ВСЕХ шаблонов, включая старые.
- `program-roadmap.tsx`: общий timeline, в том числе вложенный scroll контейнер редактора.
- `music-player.tsx` и `music-uploader.tsx`: кнопка воспроизведения и UI загрузки.
- `use-local-audio.ts` и `local-audio-store.ts`: сохранение аудио Blob отдельно от JSON черновика.
- `invitation.schema.ts`: типизированные блоки `program`, `music`, до 6 фото галереи и до 8 этапов программы.

## Известные ограничения

1. Проект пока **локальный frontend-прототип**. Серверное сохранение фото/аудио, авторизация и публикация гостям будут добавлены с backend.
2. Изображения в черновике сохраняются через `localStorage`, что ограничено квотой браузера. Музыка хранится в IndexedDB текущего браузера и не переносится на другие устройства.
3. Нельзя гарантировать автозапуск фоновой музыки со звуком — пользователь должен нажать Play.
4. RSVP пока не отправляет данные на сервер.
5. Импортированные картинки пользователя — образцы оформления. Фотографии с образцов используются только как демонстрационные там, где удалось выделить участок без оригинальных надписей. Без отдельного дизайн-исходника точная реконструкция сложной каллиграфии и графики недоступна.
6. При изменении шаблона созданные в другом браузере приглашения не синхронизируются до появления Backend.

## Локальный запуск

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
npm run test:references
npm run test:birthday
```

В этой рабочей среде `npm install` не завершился из-за сетевой недоступности npm-реестра, поэтому `typecheck`, `lint`, `build` **нельзя считать пройденными**. Проведены независимые проверки TypeScript AST, CSS и девяти конфигураций/ассетов.
