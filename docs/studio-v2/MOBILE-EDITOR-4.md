# Мобильная оболочка редактора Eventiq 4.0

Общий `UniversalMobileEditor` использует палитру лендинга и Inter Tight для мобильных контролов. Оба адаптера используют тот же холст и разрешённые поля соответствующей темы. В хедере размещены возврат, название, undo/redo, статус сохранения и публикация. Панель из пяти инструментов и навигация по секциям сохраняют доступ при 320 px. Стили шаблонов, административный Studio v2 и десктопный редактор используют свои прежние правила.

Контекстное окно получает фокус при открытии, удерживает Tab и Shift+Tab внутри и закрывается по Escape с возвратом фокуса. В мобильном режиме библиотека музыки и загрузка фотографий остаются доступными через текущие механизмы.

## Проверки

В production build на Chromium проверены RU/KY, 320/360/375/390/412/430 px, DPR 1, пролистывание, фокус, закрытие окна и отсутствие горизонтальной прокрутки. На 390 px проверены Studio v2 Love Story и legacy Editorial Riviera Wedding. Проверки клиентского редактора с изменением текста, `test:mobile-editor-v3`, `test:customer-photos` и `test:template-assets` прошли. Снимки ниже показывают работающий редактор.
