# «Ала-Тоо» в Studio v2

Пакет [ala-too.v1.json](../../templates/packages/ala-too.v1.json) добавляет свадебный шаблон `ala-too` для RU и KY. Коммит реализации — `cf652a2105c074de739e0e5ce9c37aae3e89da96`. База проверок — `main` на `59ca0c524838adf0ebc68dee9d4b3ed8bbe1231e`.

Шаблон использует UniversalMobileEditor, общий рендерер Studio v2 и существующий backend. Вариант `alpine` применяется только к документам, которые явно его выбирают. Один параметр даты связывает обложку и счётчик в часовом поясе Бишкека. Редактор сохраняет 11 полей персонализации, в том числе замену обложки, фотографии площадки и четырёх фотографий мозаики. Музыка подключается через существующий каталог. Без источника плеер скрыт. Адрес в пакете демонстрационный.

## Проверки

- **Browser и Playwright.** Browser подтвердил переход к программе и работу модальной галереи на маршруте приглашения. Playwright проверил обе локали на ширинах 320, 360, 375, 390, 412 и 430 px. Проверены отсутствие горизонтального переполнения, длинные имена, многострочный адрес, увеличение 200%, уменьшенное движение, будущий и истёкший отсчёт, доступность формы при ошибке загрузки фотографии, переход по якорю и карта. В галерее проверены свайп, клавиши, Escape и возврат фокуса. Для музыки проверены отсутствие кнопки без источника и цикл воспроизведения и паузы.
- **RSVP.** Проверены пустое обязательное имя, сообщение об ошибке сервера, сохранение введённого имени для повторной попытки, блокировка повторной отправки, успешное подтверждение, четыре гостя для согласия, ноль для отказа, закрытый и выключенный приём ответов.
- **Редактор.** Проверены редактирование длинных имён, undo/redo, восстановление локального черновика после перезагрузки и переход между секциями. Через общий загрузчик редактора проверены два одиночных фото и групповая замена четырёх фото галереи. Реальный файл HEIC в Chromium преобразован в WebP 400 × 600. Транспорт хранилища в браузерном тесте имитировал подписанные запросы R2 с проверкой размера и SHA-256.
- **Frontend.** Прошли `npm run typecheck -- --incremental false`, `npm run build` и наборы `test:ala-too`, `test:ak-orgo`, `test:kyrgyz-heritage`, `test:eventiq-mobile`, `test:editorial-ivory`, `test:customer-photos`, `test:mobile-editor-v3`, `test:studio-v2-invitation`, `test:studio-v2-appearance`, `test:studio-v2-personalization`, `test:backend-contract`. У `test:monochrome-editorial` воспроизводится исходная ошибка `ENOENT` для `public/images/monochrome-editorial/cover.webp` на чистом `main`.
- **Backend.** На отдельном PostgreSQL 17 применены пять миграций через `prisma migrate deploy`. Прошли typecheck, 18 unit-тестов и пять интеграционных тестов. Дополнительно через настоящий API проверены импорт пакета, отказ при повторном импорте, публикация в тестовый каталог, подтверждение шести загрузок, сохранение и повторное чтение черновика KY, создание выпуска, чтение опубликованной версии и запись RSVP. Сетевое хранилище заменено тестовым адаптером. Рабочая база не участвовала.
- **WebKit.** Playwright загрузил движок, но запуск заблокировали отсутствующие системные библиотеки Linux. Браузерная матрица выполнена в Chromium.

## Импорт и публикация в каталоге

Выполняйте из корня репозитория. Токен должен принадлежать администратору рабочей области, а API и ID области — указывать на нужную среду. Пример для PowerShell 7.2+.

```powershell
$env:EVENTIQ_API_BASE = 'http://localhost:4000/api/v1'
$workspace = Read-Host 'ID рабочей области'
$env:EVENTIQ_ACCESS_TOKEN = Read-Host 'Supabase access token' -MaskInput
try {
  $result = node scripts/import-eventiq-mobile.mjs $workspace ala-too
  if ($LASTEXITCODE -ne 0) { throw 'Импорт шаблона не выполнен' }
  $template = $result | ConvertFrom-Json
  Invoke-RestMethod -Method Post `
    -Uri "$env:EVENTIQ_API_BASE/workspaces/$workspace/templates/$($template.id)/publish" `
    -Headers @{ Authorization = "Bearer $env:EVENTIQ_ACCESS_TOKEN" } `
    -ContentType 'application/json' -Body '{"publicSlug":"ala-too"}'
} finally {
  Remove-Item Env:EVENTIQ_ACCESS_TOKEN -ErrorAction SilentlyContinue
}
```

После публикации шаблон доступен на `/ru/catalog/ala-too` и `/ky/catalog/ala-too`. Редактор открывается по адресу `/ru/editor?template=ala-too`. При конфликте импорта проверьте существующий шаблон и версию.
