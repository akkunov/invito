# Ак Өргө · Studio v2

Пакет `templates/packages/ak-orgo.v1.json` содержит четыре артборда 390 × 1058 px, локали RU/KY и шесть заменяемых фото. Арочная маска — свойство слоя изображения. Галерея использует общий `stackedMosaic` с пропорциями средней строки 192:167. Вариант оформления `gilded` применяет золотую палитру к общим виджетам и сохраняет минимальные размеры интерактивных элементов на узких экранах. Дата и таймер связаны с одной переменной. Адрес площадки демонстрационный.

Для импорта используется `node scripts/import-eventiq-mobile.mjs <workspaceId> ak-orgo` с `EVENTIQ_ACCESS_TOKEN` и при необходимости `EVENTIQ_API_BASE`. Скрипт создаёт версию шаблона и заполняет разрешённые источники из музыкального каталога. Публикация использует штатный API. Рабочая база и пользовательские черновики в ходе проверки не использовались.

Проверены отсутствие горизонтальной прокрутки, сохранение размера полей, переход к следующей секции, раскладка, свайп и клавиатурная навигация галереи, карта, управление музыкой, валидация RSVP, ожидание ответа, блокировка повторной отправки, обработка ошибки API и успешная отправка.
