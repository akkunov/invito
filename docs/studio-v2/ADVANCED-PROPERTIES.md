# ADR-011 — Advanced Properties and Page Management (#28.2)

Optional visual properties extend existing nodes without a migration: independent corner radii in CSS order, solid/linear gradient (2–8 ordered stops), transparent fill, solid/dashed/dotted stroke, shadow, blur, ellipse/diamond mask, X/Y reflection on image/shape leaves and bounded visual image crop. Legacy frame backgrounds, shape fills/strokes and focal settings remain readable. Corner clipping applies to frames with a positive radius; masks and crop apply to image/shape leaves. Polygon masks and strokes use CSS, not a vector path editor; the crop is non-destructive and does not alter source image bytes. Appearance is shared by artboard/preview. The inspector reuses Studio UI conventions; widget-specific background can obscure outer fill. Text/frames are not reflected to avoid invalidating nested coordinate geometry.

Page ordering is separate from world placement: drag page rows or use Up/Down buttons to reorder the invitation sections. Drag the page title on canvas to reposition. The movement is a single history transaction; pointer cancel/Escape cancels it. Delete is reversible and preserves at least one page. Undo restores the deleted subtree (with responsive overrides) and selects the restored page; Redo reapplies the deletion. Page names, layer names, layer visibility and lock state are undoable. Locked layers may be unlocked by the separate state command if their ancestor chain is writable. Assets remain in the library after page deletion.

Tests: npm run test:studio-v2-appearance. CI includes previous suites, TypeScript, and build. Browser QA pending: independent radii at different zooms, clipping, gradient edits, crop pointer/touch, page ordering vs canvas drag, delete/undo/redo, hidden and locked layers. No legacy route changes. Linked components, shared style tokens, advanced custom vector masks, arbitrary fill images and font upload remain separate follow-up work.
