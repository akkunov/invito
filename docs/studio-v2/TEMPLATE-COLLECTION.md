# Интеграция коллекции Eventiq

## Аудит

Аудит проведён на `origin/main` от `9ce36d8`. Десять дизайнов находятся в `tamplates_codex/eventiq-10-templates-codex`. Это комплект исходных материалов. Девять JSON-blueprint описывают предполагаемые поля и возможности. Для Vogue есть геометрия и спецификация. Все десять дизайнов имеют четыре растровых артборда.

| Слой | Текущий владелец | Путь интеграции |
| --- | --- | --- |
| Документ, слои и медиа | `document.schema.ts`, общие схемы Studio v2 | Версионированный пакет, общие ноды и проверяемые параметры |
| Каталог и гостевой маршрут | `CatalogService`, `StudioV2ProjectRenderer` | Публикация версии через существующий API, общий рендер |
| Редактор клиента | `CustomerMobileEditor`, `UniversalMobileEditor`, `PersonalizationContract` | Отдельные привязки для текста и фото, существующие поля программы, галереи, RSVP и музыки |
| Admin Studio v2 | `StudioV2Artboard`, свойства виджетов и версионирование | Те же слои и виджеты, оформление хранится в документе |
| Backend | `DocumentsService`, `CustomerInvitationsService`, `CustomerPublicationService`, RSVP services | Общая проверка снимка, медиа и прав. Импорт создаёт новую версию, гостевой рендер использует опубликованный снимок |

## План

1. Собрать Love Story из геометрии, медиаресурсов и локализованных данных. Добавить общий компилятор пакетов, режим адаптивного размещения, привязки к дате и общие действия. Оставить в RSVP существующие обработчики, ограничения и сохранение.
2. Проверить эталон через API в отдельной БД, в общем редакторе и на гостевой странице. Сопоставить скриншоты с оригинальными артбордами в двух локалях.
3. Применить тот же компилятор к остальным девяти. Оформление хранить в данных. Общие отличия виджетов выражать через типизированные опции.
4. Проверить TypeScript, lint, тесты, сборку и стабильность существующих пакетов. Изменения остаются в `feat/universal-template-import`.

## Использование

`npm run templates:compile` собирает все пакеты из геометрии и декларативных правил в `templates/collection/recipes.mjs`. Передача slug после `--` ограничивает сборку этим пакетом. Компилятор сохраняет координаты слоёв, локализованные привязки, WebP и точный список путей для backend. Сборка приложения использует уже подготовленные пакеты.

Пакет импортируется через существующий endpoint. На backend с коллекцией предварительно примените миграции для поля пожелания. Команда ниже работает с выбранной рабочей областью. URL API и токен администратора задаются через `EVENTIQ_API_BASE` и `EVENTIQ_ACCESS_TOKEN`.

```sh
node scripts/import-eventiq-mobile.mjs "$WORKSPACE_ID" love-story
```

Подставьте slug из таблицы для остальных пакетов. Публикация версии в каталоге выполняется через существующий Admin API. После неё клиентский редактор открывается по адресу `/ru/editor?template=<slug>`. Повторный импорт того же slug в ту же рабочую область возвращает конфликт.

## Результат

Love Story первым прошёл проверку компиляции, редактора, календаря, RSVP и публикации. На этом контракте собраны остальные девять пакетов. Все они используют тот же рендерер и те же поля UniversalMobileEditor. В Studio доступна настройка общих слоёв и новых виджетов.

Снимки сделаны на гостевом маршруте production-сборки с локальным тестовым API в Chromium при 390 × 844 и DPR 1. Использована исходная геометрия 390 и 430 px. При узкой ширине рендерер пересчитывает колонки и сдвигает следующие слои при росте текста или формы. Размеры интерактивных элементов задаются в CSS px.

Исходники фотографий и чистые вырезки использованы там, где они доступны. В нескольких дизайнах портрет или декор пришлось взять из отдельного участка артборда. Поэтому часть кадрирования, текстуры, типографики и внутренних отступов формы отличается от растрового оригинала. Cinema Wedding использует статичный кадр, поскольку видеоресурса в комплекте нет. Secret Garden и Digital Envelope открывают следующую секцию. Minimal Architecture показывает схематичные интерактивные зоны на основе редактируемой программы.

## Проверки

- `npm run test:template-collection` проверяет 10 пакетов, RU/KY, медиа, замену фото, дату, адаптацию, ICS и границы поля пожелания. 12 тестов прошли.
- В Chromium пройдены 60 комбинаций из 10 шаблонов, 2 языков и ширин 320, 390 и 430 px. Проверены четыре секции, загрузка ресурсов для снимков, отсутствие горизонтального скролла, размеры контролов и ошибки JavaScript.
- На эталоне проверены редактирование имён, переход между секциями, скачивание ICS и браузерная отправка RSVP с пожеланием. Отдельно проверены переключение снимков и возврат фокуса Art Gallery, выбор зоны Minimal Architecture, переключение месяца Secret Garden и открытие Digital Envelope.
- На отдельной PostgreSQL 17 для всех десяти пройдены импорт, отказ при дубликате, каталог, сохранение имён KY, отказ при устаревшей ревизии, публикация и идемпотентный RSVP. Пожелания возвращаются только в списке владельца.
- Прошли frontend и backend typecheck и сборки. Прошли 18 backend unit-тестов и 5 интеграционных тестов, а также 14 frontend-наборов, включая UniversalMobileEditor, загрузку фото, персонализацию, общие виджеты, Ak Orgo, Ala-Too, Shyrdak и Kyrgyz Heritage. Строгий аудит Frontend Design Premium завершился без замечаний.
- Полный ESLint завершился с 78 ошибками и 53 предупреждениями как на исходном `main` от `9ce36d8`, так и на ветке. Сравнение исходников по файлам и правилам показало ноль новых замечаний.
