# Kyrgyz Heritage

Новый Template Package `templates/packages/kyrgyz-heritage.v1.json` содержит четыре артборда 390 × 1050 px. Изображения лежат в `public/images/kyrgyz-heritage/`. Публичный просмотр и персонализация используют общие маршруты Studio v2. Формат и ручки API прежние.

Для импорта используется `node scripts/import-eventiq-mobile.mjs <workspaceId> kyrgyz-heritage` с `EVENTIQ_ACCESS_TOKEN` и при необходимости `EVENTIQ_API_BASE`. Скрипт импортирует версию в статусе draft. Разрешённые источники берутся из музыкального каталога. При необходимости `EVENTIQ_DEFAULT_MUSIC_ID` выбирает трек из этого же каталога. Публикация каталога и приглашений использует существующие операции. Адрес ресторана демонстрационный.
