## Локальный просмотр без базы данных

1. Выполните `npm ci` в корне проекта.
2. В первом терминале запустите `node scripts/fixtures/love-story.mjs`. Fixture слушает только `127.0.0.1:4281`, читает пакет из файла, возвращает синтетические ответы RSVP, короткий тестовый тон и ничего не сохраняет.
3. Во втором терминале соберите и запустите приложение с адресом локального fixture.

   ```bash
   export NEXT_PUBLIC_API_URL=http://127.0.0.1:4281/api/v1
   export NEXT_PUBLIC_SUPABASE_URL=http://localhost:4281
   export NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=fixture-test-key
   npm run build
   npm run start -- --hostname 127.0.0.1 --port 4280
   ```

4. Откройте [приглашение RU](http://127.0.0.1:4280/ru/c/love-story), [приглашение KY](http://127.0.0.1:4280/ky/c/love-story) или [редактор](http://127.0.0.1:4280/ru/editor?template=love-story). Для тестового отказа API используйте имя `Сбой`. Варианты `love-story-long`, `love-story-closed` и `love-story-unavailable` показывают длинные данные, закрытую форму и недоступность приёма. `love-story-silent` показывает релиз без аудио.
5. Для автоматического повтора укажите папку с установленным Playwright в `STUDIO_BROWSER_PREFIX`. Можно использовать системный Chromium через `CHROMIUM_PATH`.

   ```bash
   npm install --prefix /tmp/eventiq-vf-01-browser playwright@1.56.1
   /tmp/eventiq-vf-01-browser/node_modules/.bin/playwright install --only-shell chromium
   STUDIO_BROWSER_PREFIX=/tmp/eventiq-vf-01-browser \
     node scripts/fixtures/capture-love-story.mjs /tmp/eventiq-vf-01 --owner
   ```

Для базового сравнения сохраните `git show d68201b:templates/packages/love-story.v1.json > /tmp/love-story-before.json`. Запустите fixture с этим файлом как первым аргументом и откройте приложение от того же базового SHA. Режим `--capture-only` снимает исходные четыре артборда без тестов новых вариантов.

## Источники и совместимость

Источники — четыре неразмеченных PNG, `geometry.json`, спецификация, HTML-прототип и семь исходных WebP. У исходных демо-фотографий часть кадров обрезана, а два кадра содержат номер главы. Для кандидата использованы отдельные очищенные фрагменты заданного референса: фотографии, рамки, ветви, билет, марка и декоративные края. Номера глав, подписи, заголовки, время, дата и поля формы отрисовываются поверх. Бумажное зерно подготовлено отдельно. Точные размеры и байты читает `npm run templates:compile -- love-story`.

Кандидат использует те же slug и ID полей. URL ранее опубликованных ресурсов и их файлы сохранены. Новые ресурсы имеют префикс `/images/collection/love-story/vf-01/`. Файл `love-story.v1.json` по-прежнему использует формат пакета v1. Его обновление в рамках этого PR не публикует версию в базе. Импорт и переключение публичной версии относятся к [TPL-02](../architecture/tasks/TPL-02-append-template-version.md) и [TPL-04](../architecture/tasks/TPL-04-template-version-rollout.md).

Движок использует опциональные параметры текста и виджетов. Старые документы без этих параметров продолжают работать по прежним правилам. Остальные случаи для общего движка зафиксированы в [ENG-01](../architecture/tasks/ENG-01-renderer-fidelity-contract.md#наблюдения-vf-01) и [ENG-02](../architecture/tasks/ENG-02-renderer-optional-capabilities.md#наблюдения-vf-01).

## Музыка и безопасная загрузка

Редактор показывает «Загрузить MP3» в инструменте «Музыка» у шаблонов с разрешением `allowUpload`. Нужен аккаунт. Лимит MP3 — 15 МБ и 15 минут. Общий путь загрузки проверяет байты, SHA-256, MIME и MP3 на сервере. Сохранение и публикация проверяют владельца, личный Workspace и статус READY. Черновик и релиз хранят ссылку на верифицированный файл. В публичном приглашении звук включается по нажатию. У пакета пустой источник по умолчанию и карточка появляется после выбора трека.

Playwright подставляет тестовую сессию и перехватывает запросы R2. Старый контракт сохраняет список разрешённых треков. Обычный издательский workflow, настройки проекта и старые URL ресурсов сохранены. [Политика медиа](../backend/ADR-029-04-MEDIA.md)
