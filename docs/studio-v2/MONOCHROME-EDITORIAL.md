# Monochrome Editorial — ресурсы и проверка

Пакет впервые появился в коммите `35efbc58678f424f246996f5db5c3635bc149f9f` без WebP-файлов. В доступной полной истории 60 remote refs, в тегах и в локальных вложениях оригиналы и `eventiq-monochrome-assets.zip` не нашлись. Путь не исключён Git. Воссозданы шесть чёрно-белых изображений по назначению и пропорциям из пакета. Фотографии синтетические. Исходные размеры, имена файлов, asset IDs, размещение, responsive overrides и связи с полями редактора сохранены. Синхронизирован размер в байтах.

В четырёх bundled-пакетах Editorial Ivory значения `sizeBytes: 1` и размеры-заглушки заменены фактическими параметрами трёх исходных WebP. Для двух подписанных дизайнером полей добавлен опциональный `allowOriginalResolution`. Он разрешает сохранить точно тот встроенный образец, который был задан автором для поля. Подмена образца другим фото и пользовательская загрузка проверяются прежними ограничениями. Старые пакеты без этого свойства по-прежнему применяют прежние правила.

Работа сохраняет storage keys и совместима с уже опубликованными ссылками. Действующие версии в БД, черновики, снимки публикаций, их хеши и ответы гостей не изменялись. Для уже опубликованного Monochrome Editorial браузер получает изображения по тем же статическим URL. Повторная публикация для этого не требуется.

## Проверки

- `npm run test:template-assets` проходит по всем 20 bundled-пакетам, 171 ссылке и 162 уникальным путям. Проверяет Studio v2 контракт, наличие cover page, фактический тип, длину, заявленные пиксельные размеры, декодирование и границу `public/images`. SVG с CRLF проверяются тем же helper, что используется при импорте. Проверка подключена к CI.
- На отдельной PostgreSQL 17 проверены импорт Monochrome Editorial, защита от дубля, сохранение KY-черновика, отказ при устаревшей ревизии, публикация, повторное чтение и идемпотентность RSVP. Пройдены backend typecheck, production build, 18 unit и 5 e2e.
- В Playwright Chromium сверены detail, публичное приглашение и редактор при ширинах 320, 360, 375, 390, 412 и 430 px в RU/KY. Шесть изображений декодируются на detail и публичной странице. В исправлении также стабилизирован формат KY-даты между сервером и браузером с неполным набором ICU.
- Прошли frontend typecheck, production build, 44 проверки npm вне отдельного браузерного набора, Chrome-проверки клиентского редактора, публичного RSVP и нагрузочного проекта Admin Studio v2. Root lint сохраняет исходные 78 ошибок и 53 предупреждения. Изменённые скрипты и core-файлы прошли scoped lint. WebKit на этом хосте не запустился из-за отсутствующих системных библиотек.
