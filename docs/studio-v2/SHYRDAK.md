# «Шырдак» в Studio v2

Пакет [shyrdak.v1.json](../../templates/packages/shyrdak.v1.json) добавляет свадебное приглашение `shyrdak` на русском и кыргызском. Коммит реализации — `719554b226f3f25f24758996ed5b6f617243c5c2`. База проверки — `main` на `902b48170e933d2f0fd0eed2e17ea75cdc6c08d0`.

Приглашение использует UniversalMobileEditor, общий рендерер Studio v2 и существующие API для загрузки фото, черновиков, публикации и RSVP. Редактируются 11 полей, включая шесть фотографий. Орнаменты и фактура принадлежат пакету, заблокированы и скрыты от скринридера. Дата в часовом поясе Бишкека управляет датой на обложке и обратным отсчётом.

Опциональный `visual.clipPolygon` хранит от 3 до 64 пар координат в процентах. Общий рендерер применяет один контур в редакторе, предпросмотре и опубликованной версии. Замена портрета сохраняет контур. Раскладка `schedule.layout: "rows"` задаёт горизонтальные разделители. Вариант `felt` задаёт палитру, шрифты, геометрию и состояния общих контролов.

## Проверки

- **Browser и Playwright.** Browser подтвердил переход к программе и открытие и закрытие галереи. Playwright проверил RU и KY на ширинах 320, 360, 375, 390, 412 и 430 px, длинные имена и адрес, увеличение 200%, уменьшенное движение, системную тёмную тему, будущий и истёкший отсчёт, галерею с 1–4 фото, свайп, клавиши, Escape и возврат фокуса. Проверены карта, пустой музыкальный виджет и ручное воспроизведение из источника.
- **RSVP.** Проверены валидация пустого имени, ошибка сервера с сохранением имени, повторная попытка, блокировка повторной отправки в процессе запроса, успех, согласие с четырьмя гостями, отказ с нулём гостей, закрытый и отключённый приём. При ошибке загрузки портрета форма оставалась доступна.
- **Редактор.** Проверены длинные имена, undo/redo, восстановление локального черновика, переходы между страницами, замена обложки и фото площадки, пакетная замена четырёх фото галереи. Реальный файл HEIC преобразован общим загрузчиком в WebP 400 × 600. В браузерном тесте запросы к R2 имитировались с проверкой размера и SHA-256.
- **Frontend.** Прошли `npm run typecheck -- --incremental false`, `npm run build` и наборы `test:shyrdak`, `test:ala-too`, `test:ak-orgo`, `test:kyrgyz-heritage`, `test:eventiq-mobile`, `test:editorial-ivory`, `test:customer-photos`, `test:mobile-editor-v3`, `test:studio-v2-invitation`, `test:studio-v2-appearance`, `test:studio-v2-personalization`, `test:studio-v2-motion`, `test:backend-contract`. В дополнительном `test:monochrome-editorial` воспроизводится известная ошибка `ENOENT` для `public/images/monochrome-editorial/cover.webp`. Аудит Frontend Design Premium в строгом режиме завершился без замечаний.
- **Backend.** На отдельном PostgreSQL 17 применены пять миграций. Прошли typecheck, сборка, 18 unit-тестов и пять интеграционных тестов. Через API проверены импорт, отказ при повторном импорте, публикация в тестовый каталог, подтверждение шести загрузок, сохранение черновика KY, отказ при устаревшей ревизии, чтение опубликованной версии с той же маской и запись RSVP. Сетевое хранилище в этой проверке заменено тестовым адаптером.

## Импорт в каталог

Пример для PowerShell 7.2+. Запускайте из корня репозитория с токеном администратора целевой рабочей области. Используйте адрес API этой среды.

```powershell
$env:EVENTIQ_API_BASE = 'http://localhost:4000/api/v1'
$workspace = Read-Host 'ID рабочей области'
$env:EVENTIQ_ACCESS_TOKEN = Read-Host 'Supabase access token' -MaskInput
try {
  $result = node scripts/import-eventiq-mobile.mjs $workspace shyrdak
  if ($LASTEXITCODE -ne 0) { throw 'Импорт шаблона не выполнен' }
  $template = $result | ConvertFrom-Json
  Invoke-RestMethod -Method Post `
    -Uri "$env:EVENTIQ_API_BASE/workspaces/$workspace/templates/$($template.id)/publish" `
    -Headers @{ Authorization = "Bearer $env:EVENTIQ_ACCESS_TOKEN" } `
    -ContentType 'application/json' -Body '{"publicSlug":"shyrdak"}'
} finally {
  Remove-Item Env:EVENTIQ_ACCESS_TOKEN -ErrorAction SilentlyContinue
}
```

После публикации карточки доступны по маршрутам `/ru/catalog/shyrdak` и `/ky/catalog/shyrdak`. Редактор открывается через `/ru/editor?template=shyrdak`. При конфликте проверьте, какой шаблон и какая версия уже в каталоге.
