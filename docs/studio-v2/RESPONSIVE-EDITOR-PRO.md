# ADR-015 — Responsive Editing Pro (#28.6)

Responsive Studio is an isolated authoring workspace with Desktop, Tablet and Mobile artboards of the same selected page. It shares the existing Artboard, content binding, style resolution and layout solver. The author switches page/device/layer, or selects the layer directly on an artboard. All three remain visible side-by-side on wide screens; narrow screens scroll horizontally. Selection is shared across devices, and hidden layers remain accessible through the layer selector.

The canonical project graph and text content remain unchanged by device edits. Existing optional per-device geometry, visibility, opacity and rotation overrides are extended with type-specific typography (size, line height, tracking, alignment) and frame layout (mode, gap, alignment, distribution, padding). Page-root layout overrides are allowed, but root geometry still uses page profiles. Responsive typography wins over shared token typography for the overridden properties only. Omitted values inherit the base, not another device. Nested empty overrides are normalized out. No schema version change is required.

The render order remains content binding -> shared style/theme resolution -> responsive overrides -> layout -> Artboard. Intrinsic text height is measured independently per device. Scale mode preserves canonical design units and scales the artboard. Reflow mode uses the device root size, existing anchors and auto layout. Layout-only edits can use either mode; a switch from device hug layout to free resolves hug to fixed in the derived document.

Direct pointer gestures: single visible, unlocked free-positioned node moves in parent-local coordinates, accounting for rotation, artboard display scale and anchor offsets. A southeast resize handle is available for fixed-size layers with start anchors, including rotated layers; Shift preserves proportions. Fill/hug, stretch/center/end anchored resize, auto-height text and auto-layout child drag are deliberately not offered because those sizes/positions are solver-controlled. Use the frame's layout controls instead. A gesture previews a draft command locally and commits exactly once on pointer-up; pointer cancellation discards the draft. No document changes during drag until commit. Undo/Redo shares the existing history, including keyboard shortcuts when focus is outside form fields. Numeric coordinates are authored (not solved) units. Root layout changes do not rewrite base layer positions. The root's entire padding value is one grouped override; clearing a padding side clears the group.

Scope: geometry and layout/typography per device, single-layer direct manipulation, no device-specific tree topology, no free-frame stacking reorder via drag, no multi-selection gestures in responsive workspace, no content duplication. The separate base editor retains all existing tools. Legacy routes unchanged. Existing preview and future published rendering use the same responsive resolver. Browser support for native touch/Safari requires separate manual verification.

Tests: npm run test:studio-v2-responsive-pro. Chromium verifies three simultaneous artboards, drag/resize isolation, one-step undo, typography, device visibility, root layout/reset. Both CI workflows run the new suite. Do not merge without current-head checks.
