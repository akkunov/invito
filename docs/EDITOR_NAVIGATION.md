# Навигация по секциям редактора (v0.4)

- При нажатии на пункт **Обложка / Дата и время / Программа / Фотогалерея** предпросмотр телефона прокручивается к соответствующему `data-editor-block` в текущем шаблоне.
- При ручной прокрутке предпросмотра подсвечивается секция, пересекающая линию чтения (~35% от верхней части viewport), и инспектор автоматически показывает настройки этой секции.
- Работает для трёх birthday-шаблонов, девяти reference-шаблонов и стандартных шаблонов через единые маркеры. Не завязано на порядок блоков; перестановка поддерживается.
- Скрытые секции не присутствуют в DOM. Их можно выбрать в боковой панели и включить, но предпросмотр не прокручивается к невидимому элементу.
- Музыка отображается как отдельный плавающий плеер и не является scroll-секцией; её выбор открывает настройки без прокрутки.
- Программная плавная прокрутка не должна менять выбранный блок до завершения анимации; ручной wheel/touch/keyboard снимает эту блокировку.
- Системная настройка `prefers-reduced-motion` отключает плавную прокрутку. На мобильном горизонтальный список блоков сам прокручивается к активному элементу.

## Локальная проверка

```bash
npm install
npm run typecheck
npm run test:editor-navigation
npm run build
```

Откройте `/ru/editor?template=midnight-aura`, выберите **Дата и время**, затем прокрутите телефон до **Программа** и проверьте подсветку. Повторите для `soft-bloom`, `golden-milestone`, а также `reference-*` из каталога.
